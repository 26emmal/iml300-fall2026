Project 2: HyperNarrative

Concept
Final: Friendship Simulator

My project is a critique on dark UX patterns made to trick and deceive users, using the framework of a stereotypical "cute" anime Otome game. It utilizes the contrasting pink game UI from the otome game with sleek, corporate, uncolored popups typically found on corporate websites, creating a false sense of security through the wholesome aesthetics of the game and catching users off guard. The site utilizes dark UX patterns including confirm shaming, nagging, preselection, trick question, and hidden ads. The primary character's name is "Sora," referencing both traditional Japanese names to allude to the otome game theme and the AI agent Sora, highlighting both the innocent Otome theming and corporate businesses. The project also utilizes irony through the character's dialogue as she expresses how much trust is involved in her and the user's friendship, which contrasts the site's dark UX patterns deliberately breaking the user's trust.
